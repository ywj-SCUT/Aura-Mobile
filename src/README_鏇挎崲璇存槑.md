# Aura 前端收藏云同步修复版

## 本次修复的根因

旧版收藏同步存在四个问题：

1. 收藏按钮调用 `saveFavorites()` 时没有等待网络结果，用户马上退出时请求可能还没有完成。
2. 多次快速收藏或删除会并发发送请求，旧请求可能比新请求更晚完成，从而用旧收藏覆盖新收藏。
3. 旧代码只检查 HTTP 状态，没有读取后端 JSON 中的 `success: false`，因此后端拒绝保存时前端也不会提示。
4. 退出登录会直接清空本地收藏，即使云同步失败也继续退出，重新登录后自然只能看到云端旧数据。

## 新版行为

- 收藏变化先立即保存到本机，并写入“待同步”标记。
- 所有云端更新严格串行执行，最后一次修改一定最后写入。
- 同步会检查 HTTP 状态及后端返回的 `success` 字段。
- 网络失败会保留本机数据和待同步标记，应用下次启动后自动重试。
- 点击退出登录时先等待收藏同步完成；失败时允许重新同步、取消退出，或明确选择仍然退出。
- 应用进入后台时使用 `keepalive` 尽力补传。
- 账号窗口会显示“正在同步 / 已同步 / 同步失败”等状态。

## 替换方法

将本目录下所有文件覆盖到原前端目录：

- index.html
- style.css
- script.js
- store.js
- utils.js
- audio.js
- services.js
- ui.js
- default-cover.svg

API 地址使用占位符：

`http://YOUR_SERVER_IP:3000/api`

使用前请将 `YOUR_SERVER_IP` 替换为自己的后端 IP 地址或域名。

底部导航仍然只有文字，歌词翻译仍已删除。
